# ShopNow — Boutique GitHub Pages

Boutique statique en HTML/CSS/JavaScript, sans serveur ni build, prête pour GitHub Pages.

## Pages
- `index.html` — Accueil
- `boutique.html` — Catalogue
- `produit.html` — Produit
- `a-propos.html` — À propos
- `contact.html` — Contact

## Publication
Dans GitHub : **Settings → Pages → Deploy from a branch → main → / (root) → Save**.

Le panier de démonstration utilise `localStorage`. Aucun paiement réel n'est configuré.
